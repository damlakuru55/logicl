# Challenge Design Guide

## Goals
- Keep each challenge focused on one logical idea.
- Provide immediate, understandable feedback.
- Keep controls usable on small screens.

## Recommended Structure
1. Present the problem clearly.
2. Offer a small set of choices.
3. Validate the selected answer.
4. Explain the result briefly.

## Accessibility
Use clear labels, keyboard-friendly controls, and sufficient text contrast when adding new challenges.
